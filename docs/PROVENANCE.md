## New public glue

`storage.py`, `synthetic.py`, `report.py`, `cli.py`, research drivers and their
additional tests are new public integration code. The sentiment/price driver
uses the ported heuristic, not either ML experiment's classifier. It uses only
headlines from a completed UTC calendar day before deciding exposure at a later
close, then earns returns over the following interval. Its breaker counts each
held interval's PnL net of the preceding close's cost, in starting-capital units.
The library retains explicit-reset behavior. Demo callers explicitly reset every
five observed sessions, exporting the resets and shaded pause spans. End-of-sample holdings
are marked to market; no terminal liquidation is simulated.

## Bundled data

`src/fdp/fixtures/` contains 260 business-day observations for three fictional
assets (780 price rows) and 260 fictional headlines. Generated by
`fdp.synthetic.generate_fixtures`, seed 42; `manifest.json` describes the process.
Prices and headlines are generated independently. These files contain no
third-party data and are licensed with this repository under MIT. No external
model or dataset is needed for `fdp demo`.

Optional RSS downloads are user-triggered, transient provider content. They are
not included in the demo, tested with live requests, bundled or automatically
published. Public availability does not imply unrestricted redistribution.

The public synthetic generator `planted_inputs` accepts a conditional effect in
basis points. The report's predeclared grid is 0, 5, 10, 20 and 40 bp, with the
same 60 bp innovations, 5,200 sessions, 5 bp costs, five-session guard reset policy,
seeds 100–119 and gates for every row. Headlines and innovations are paired across
effects. `scripts/detection_power.py` precomputes all 100 outcomes in the bundled
JSON ledger, which the report validates before displaying counts. Zero effect
is labeled the false-positive rate. The primary-seed chart is fixed at seed 43
and 20 bp, regardless of outcome; it is illustrative rather than the result.
No private research records or external data enter this experiment.

## Preserved experiments and private boundaries

`ml-experiments/` is unchanged, including its reported metrics, dataset pins,
download helper, commands and limitations. Its third-party training data must
still be downloaded separately according to those documented terms. The MIT
license for code does not relicense third-party datasets.

Broker/exchange/wallet integrations, Telegram, cloud/deployment scripts,
credentials, account identifiers, operational records, private raw data and
private performance records remain private. No source repository file was
modified or executed. No inference about profitability follows from these ports.
